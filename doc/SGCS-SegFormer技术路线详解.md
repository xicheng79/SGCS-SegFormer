# SGCS-SegFormer 技术路线详解

> 本文档整合 SGSW 模块、TBTI 模块（含 FTC/FTP 操作与注入位置）、整体架构以及推理策略，完整说明 SGCS-SegFormer 的工作流程。

---

## 一、总体架构概览

SGCS-SegFormer 在原始 SegFormer（MiT-B2 骨干 + 轻量 All-MLP 解码头）基础上，引入两个即插即用模块：

| 模块 | 作用阶段 | 核心功能 |
|------|----------|----------|
| **SGSW**（Spectral-Guided Sliding Window） | 训练数据组织 | 用 NDWI 光谱信息优先化采样，构建有序 sample queue |
| **TBTI**（Template-Based Training Interaction） | 跨样本特征传递 | 将前一样本的高语义特征模板注入下一样本的浅层编码器 |

两个模块均为**训练时专属**机制，推理时不参与（详见第五节）。

---

## 二、SGSW 模块：光谱引导的训练样本队列构建

### 2.1 核心思路

传统滑动窗口按固定顺序（行优先光栅扫描）切割 patch，无法优先覆盖目标区域。SGSW 用 NDWI 积分图驱动**贪心搜索**，将水体区域排在队列前端，实现课程式学习（Curriculum Learning）。

### 2.2 积分图加速（O(1) 区域求和）

输入影像预先计算 NDWI 波段的**积分图**，使任意矩形区域的 NDWI 总值可在 O(1) 时间内查询，全局光谱扫描的额外开销可忽略不计。

### 2.3 主搜索阶段（Primary Phase）

1. **初始化**：在所有候选窗口位置中，选取 NDWI 总值最高的位置作为初始采样位置（ISP）：
   $$ISP = \arg\max_{x,y \in W} NDWI(x, y) \tag{1}$$

2. **迭代搜索**：每次迭代从当前位置 $SP_i$ 的八邻域中选取 NDWI 最高的未访问窗口：
   $$SP_{i+1} = \arg\max_{x,y \in N(SP_i)} NDWI(x,y), \quad i \geq 0, \quad SP_0 = ISP \tag{2}$$

3. **终止条件**：满足以下任一条件时，主搜索阶段自动终止，剩余区域转入补充扫描段：
   - 当前位置的所有八邻域窗口均已被访问；
   - 八邻域中 NDWI 最高的候选窗口，其 NDWI 区域和低于全局相对阈值 $T$（详见 §2.7）。

4. **方向记录**：每步的移动方向 $D_i$ 与位置 $SP_i$ 打包为元组 $(SP_i, D_i)$，保存至队列，用于后续 TBTI 的空间定位。

### 2.4 补充扫描阶段（Supplementary Phase）

主搜索结束后，图像中可能仍有未覆盖区域。补充阶段以**光栅扫描**方式遍历剩余区域，不再使用 NDWI 引导。由于该阶段可能跨越空间不相邻的区域，跳跃点处设置 $D_i = (0,0)$，TBTI 特征注入在此阶段**显式禁用**，仅保证空间完整覆盖。

### 2.5 队列结构

最终训练样本队列由两段连续子序列构成：

```
[ NDWI引导的主搜索段（含TBTI激活） | 光栅扫描的补充段（TBTI禁用） ]
  ←──── 水体优先，空间连续 ────────→ ←── 背景补全，可跨区域 ──→
```

这一双段结构实现了**课程学习策略**：模型先在光谱信息丰富、空间连续的水体区域上进行有 TBTI 增强的训练，再在背景区域上进行标准训练，巩固背景判别能力。

### 2.6 窗口参数

| 参数 | 值 | 说明 |
|------|----|------|
| 窗口大小 | 512 × 512 px | Transformer 感受野与计算量的最优均衡 |
| 水平重叠区 | 128 × 512 px | 水平滑动时的相邻重叠带 |
| 垂直重叠区 | 512 × 128 px | 垂直滑动时的相邻重叠带 |
| 对角重叠区 | 128 × 128 px | 对角滑动时的相邻重叠角 |

## 三、TBTI 模块：跨样本特征模板传递

### 3.1 Feature Template（FT）的定义

FT（特征模板）是从**相邻两个样本的空间重叠区域**提取的深度语义特征切片，随新样本动态更新。FT 捕捉的是**解码特征**（而非原始图像像素），携带了多尺度融合后的高语义表达。

### 3.2 FTC（Feature Template Cropping）——特征模板裁剪

**执行位置：解码头（Decode Head）**，作用于多尺度融合后的 `out_overlap` 特征图。

**操作流程：**
1. 解码头融合 Stage 1～4 的多尺度特征，输出高语义融合特征图 $FM_i$；
2. 利用 SGSW 队列记录的路径信息 $(SP_i, D_i)$ 确定重叠区域的空间位置；
3. 从 $FM_i$ 中精确裁剪出对应重叠区的特征切片，得到 FT：
   $$FT = FTC\bigl(CAR(FM_i),\ (SP_i, D_i)\bigr) \tag{4}$$

其中 $CAR(\cdot)$（Cross-sample Attention Reformer）将特征图从 $N \times (H \times W) \times C$ 重排为 $N \times C \times H \times W$，使空间维度与位置索引对齐。

**在解码头执行的原因：** 解码头融合了 Stage 1～4 的全尺度信息，FT 因此携带最丰富的语义表达；同时解码头输出的特征图分辨率已恢复（相对 Stage 4 更高），裁剪精度更高。



### 3.3 FTP（Feature Template Pasting）——特征模板粘贴

**执行位置：当前样本编码器的第一阶段（Stage 1，MiT 的最浅层）。**

**操作流程：**
1. 获取前一样本传入的 FT；
2. 在当前样本 $i+1$ 的 Stage 1 编码器处理完毕后，生成特征图 $FM_{i+1}^{Stage1}$；
3. 根据路径信息 $(SP_i, D_i)$，将 FT 粘贴覆盖到 $FM_{i+1}^{Stage1}$ 的对应重叠区域（其余区域被 mask 保护）：
   $$FM_{i+1}^{Updated} = FTP(FM_{i+1}^{Stage1}, FT, (SP_{i+1}, D_{i+1}))$$

**为何选择在 Stage 1 (H/4 × W/4) 注入？（三大核心优势）**
这种"**从解码头提取，向最浅层注入**"的不对称跨级设计（Asymmetric Cross-level Transfer），构成了样本间的**隐式知识蒸馏**：
1. **最高空间对齐精度**：Stage 1 维持着最高的分辨率 (H/4 × W/4，对 512×512 输入即 128×128)。在这一层执行特征块粘贴，重叠区域的像素级空间对应关系最为精确。
2. **充分的后续精化空间**：将富含高层语义的特征注入浅层后，后续的三个编码阶段（Stage 2-4）有充足的深度和容量（Receptive Field），逐步将外来模板特征与当前样本的局部特征融合精化。
3. **最长的梯度回传路径**：注入 Stage 1 使得梯度的反向传播必须完整穿越 Stage 2/3/4 及解码头，模型能更有效地学习和调整跨样本特征融合的行为模式。

## 四、整体工作流总结（SGCS-SegFormer 训练过程）

网络包含上下两个平行分支，分别处理前一样本（Sample $i$）和当前样本（Sample $i+1$），形成串联迭代流：

1. **样本队列生成**：SGSW 模块生成包含 $(SP_i, D_i)$ 的训练队列；
2. **前一样本前向传播**：Sample $i$ 经过完整 Encoder (Stage 1-4) 和 Decode Head；
3. **FTC 提取**：从 Sample $i$ 的 Decode Head 输出中，基于 $D_i$ 提取高语义特征切片 FT；
4. **当前样本浅层编码**：Sample $i+1$ 经过 Encoder Stage 1；
5. **FTP 注入**：将 FT 粘贴到 Sample $i+1$ 的 Stage 1 特征图中；
6. **当前样本深层编码与解码**：更新后的特征继续通过 Stage 2-4 和 Decode Head；
7. **迭代**：Sample $i+1$ 成为新的前一样本，循环执行。

*(注：当 $D_i = (0,0)$ 即发生空间跳跃时，FTP 操作被禁用，当前样本执行正常的自注意力计算。)*

## 五、推理策略（Inference Strategy）

### 5.1 训练与推理的不对称性

SGCS-SegFormer 在设计上采用了**训练与推理不对称**（Training-Inference Asymmetry）的策略：
- **训练阶段**：激活 SGSW (按 NDWI 优先级打乱常规顺序) + 激活 TBTI (跨样本特征传递)。
- **推理阶段**：**禁用 SGSW 和 TBTI**。直接使用标准的光栅扫描（Raster-scanned Overlapping Sliding Window）逐个 Patch 独立预测，不进行任何跨样本的信息传递。

### 5.2 为何推理时不使用 SGSW？
SGSW 在训练中的本质是一个 **数据重组器（Curriculum Learning Data Organizer）**。它通过将光谱信息丰富的难样本（水体及其边界）优先送入网络，重塑了优化轨迹，引导权重矩阵更早、更好地学习水体表征。
**训练完成后，这种"课程学习"的收益已经彻底内化（absorbed）为模型参数（权重）的一部分。** 推理时由于任务是全面覆盖测试集图像的所有区域，不需要也不应使用优先级采样，标准的光栅扫描是最高效和完备的选择。

### 5.3 为何推理时不使用 TBTI？
TBTI 在训练中的本质是一个 **空间连续性正则化器（Training-time Regularizer for Spatial Continuity）**。
- **强制约束**：在训练中强制在浅层混入外部的高级语义特征，迫使编码器学会在扰动中提取更具鲁棒性和边界感知能力（boundary-aware）的表征。
- **泛化表现**：消融实验（§4.4）表明，模型在具备了这种更强的表征能力后，**即使在推理时没有显式的跨 Patch 通信，单 Patch 独立预测也能展现出极高的一致性和精确的边界分割效果。**

*(注：尽管当前独立推理已达到领先性能，但在论文 §5.2 的展望中提到，未来可以探索一种"轻量级推流（Lightweight sequential pass）"，即在推理时光栅扫描的过程中，沿着扫描方向顺滑传递解码头特征，以期进一步提升拼接处的连贯性。)*
