# SGCS-SegFormer 推理结果分析报告

> 模型：PanoOptiNet_EncoderDecoder（MiT-B4 骨干）  
> 配置文件：`segformer_mit-b4_greenland-0331.py`  
> 报告日期：2026-04-04

---

## 一、推理结果现象描述

| 场景 | 表现 | 对比标准 SegFormer |
|---|---|---|
| 大面积水体（湖泊、宽河道） | 边缘形态**连续、自然**，轮廓完整 | ✅ **优于**标准 SegFormer |
| 小型水体（小水塘、细碎水面） | 存在一定**假阳性**（非水体被识别为水体） | ❌ 劣于标准 SegFormer |
| 细长河道 | 存在一定**间断**（局部漏检，导致河道不连续） | ❌ 劣于标准 SegFormer |

大面积水体的优势印证了 SGCS 的核心设计目标（SGSW 课程学习 + TBTI 跨样本特征传递）已生效。  
小水体假阳性和细河道间断则揭示了训练数据分布偏斜、损失函数和推理策略的局限。

---

## 二、问题根因分析

### 2.1 训练样本分布偏斜（根本原因）

SGSW 以 NDWI 积分值贪心搜索，**主搜索段**（TBTI 激活）的 patch 绝大多数覆盖大面积连续水体。  
细长河道与小型水体的单窗口 NDWI 积分值低，系统性地排到**补充扫描段**（TBTI 禁用），导致：

- 大水体训练充分 → 边缘识别准确连续；  
- 小水体/细河道训练不足 → 模型将大水体纹理泛化，产生假阳性；细目标敏感度低，产生间断。

### 2.2 损失函数对类别不平衡处理不足

原始 `CrossEntropyLoss`（等权重）在含细河道的 patch 中，背景像素对梯度的贡献压倒水体像素，  
模型倾向于将边界像素预测为背景（保守策略），直接导致细河道的间断。

### 2.3 训练 pipeline 缺少光度增强

原始 pipeline 无任何数据增强，模型对光照变化、季节性色调偏移缺乏鲁棒性，  
光照相近的阴影/湿润土壤在 RGB 特征空间与水体高度重叠，增大假阳性风险。

### 2.4 推理滑窗步长过大，细目标跨界

原始 `stride=(341,341)`，相邻窗口仅重叠 171px。  
细长河道若恰好跨越两个窗口边界，两侧均只露出局部，上下文不完整，导致边界处漏检。

## 三、本轮配置修改内容

### 3.1 损失函数：CE + Dice 组合（最优推荐）

```python
# 修改前
loss_decode=dict(type='CrossEntropyLoss', use_sigmoid=False, loss_weight=1.0)

# 修改后
loss_decode=[
    dict(type='CrossEntropyLoss', use_sigmoid=False,
         class_weight=[0.3, 0.7], loss_weight=1.0),
    dict(type='DiceLoss', loss_weight=1.0)
]
```

**选择依据：**

| 机制 | 作用 |
|---|---|
| `class_weight=[0.3, 0.7]` | 水体像素权重提升至背景的 2.3 倍，直接对抗类别不平衡 |
| `DiceLoss` | 天然以前景/背景比率归一化，对小目标/细目标敏感；与 CE 互补，CE 负责像素级校准，Dice 负责区域级完整性 |
| 双损失并联（各 weight=1.0） | 两个损失的量级相近，无需额外调权 |

**预期改善：** 细河道间断减少，小水体漏检率下降。

### 3.2 训练增强：PhotoMetricDistortion

```python
# 在 Normalize 前插入
dict(type='PhotoMetricDistortion'),
```

**选择依据：**  
`PhotoMetricDistortion` 只改变亮度、对比度、饱和度、色相，**不改变像素空间位置**，  
完全兼容 TBTI 的 `ftc_side/recv_side` 几何对齐约束，是当前框架下唯一可安全应用于主搜索段的增强。

**预期改善：** 模型对光照变化/季节色调偏移的鲁棒性提升，假阳性（光谱相似非水体）减少。

### 3.3 推理滑窗步长：341 → 256

```python
# 修改前
test_cfg=dict(mode='slide', crop_size=(512, 512), stride=(341, 341))

# 修改后
test_cfg=dict(mode='slide', crop_size=(512, 512), stride=(256, 256))
```

**选择依据：**

| 参数 | 重叠量 | 细目标边界覆盖次数 |
|---|---|---|
| stride=341 | 171 px（33%） | 约 1～2 次 |
| stride=256 | 256 px（50%） | 约 2～3 次 |

重叠区从 1/3 增至 1/2，细河道跨界区域被至少两个窗口充分覆盖并加权平均，  
边界处预测一致性显著提升。推理时间增加约 1.8 倍，可接受。

## 四、改进方向预期效果汇总

| 问题 | 修改项 | 预期改善 | 优先级 |
|---|---|---|---|
| 细河道间断 | CE+Dice 组合损失 + stride 减小 | 间断明显减少 | 🔴 高 |
| 小水体假阳性 | PhotoMetricDistortion + class_weight | 假阳性有所下降 | 🔴 高 |
| 推理边界不一致 | stride 256 | 拼接线伪影减少 | 🟡 中 |

## 五、后续优化建议（未在本轮实施）

1. **引入 NDWI 作为第 4 输入通道**（`in_channels=4`）：最直接区分水体与光谱相似非水体（阴影/湿土），  
   预计可大幅降低假阳性，但需重新生成训练数据并重置预训练权重首层。

2. **SGSW 二次贪心路径**：主搜索终止后以次高 NDWI 窗口为新起点，专门覆盖次要水体/细河道，  
   增加小目标在 TBTI 激活段的训练比例。

3. **补充扫描段离线几何增强**：对 `ftc_side=-1, recv_side=-1` 的 patch（无 TBTI 约束），  
   离线生成 RandomFlip/RandomRotate90 副本，增加细河道多方向训练样本。

4. **推理后处理**：面积阈值过滤（去除孤立小噪点）+ 形态学闭运算（修复细河道间断缺口）。
