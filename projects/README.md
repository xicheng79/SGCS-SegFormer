# 项目

由于对代码质量的严格要求，将新模型和功能集成到 OpenMMLab 的算法库中可能会比较麻烦，这可能会阻碍最先进（SOTA）模型的快速迭代，并且可能会让我们的成员不愿在此分享他们的最新成果。

这就是我们现在有这个 `Projects/` 文件夹的原因。在这个文件夹中放置了一些实验性的功能、框架和模型，它们只需满足最低的代码质量要求，并且可以作为独立的库使用。如果用户[从源代码使用 MMSegmentation](https://mmsegmentation.readthedocs.io/en/latest/get_started.html#best-practices)，欢迎使用这些内容。

欢迎大家将任何好想法的实现发布到这个文件夹中！如果您希望启动自己的项目，请参考[示例项目](example_project/)以获取最佳实践。

注意：MMSegmentation 的核心维护人员仅确保每个项目提交时结果可复现且代码质量符合其声称的标准，但他们可能不负责未来的维护工作。原始作者负责维护自己的项目。
